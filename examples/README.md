# Runnable examples

Every script here runs standalone from the **repository root** with no
arguments:

```bash
python examples/<script>.py
```

Each script writes its figures into [`images/`](images/) and is named after the
example that produced it, so a figure can be traced back to its script from the
filename alone. The conventions the whole directory follows — a
physics-carrying module docstring, `Agg` before `pyplot`, the repo root placed
on `sys.path`, numbers derived from library closed forms rather than hard-coded,
and no output written outside `images/` — are specified in the `runnable-examples`
capability (`openspec/specs/runnable-examples/spec.md`).

The examples are the conceptual layer. `reproductions/` is the quantitative one:
each of those folders checks a specific published figure against a specific
paper, and its README records the deviations. An example that claims to
validate something against the literature should point at the reproduction
rather than restate its numbers.

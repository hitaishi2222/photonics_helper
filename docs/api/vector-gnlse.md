# Vector (polarization-coupled) GNLSE

Split-step Fourier solver for the coupled two-polarization GNLSE: per-axis
dispersion, XPM + coherent polarization FWM, differential group delay, the
Manakov (8/9) polarization-averaged mode, and a random-birefringence engine
that converges to the Manakov model. Docstrings are the source of truth,
rendered with [mkdocstrings](https://mkdocstrings.github.io/) (numpydoc
style). See [Vector GNLSE](../vector-gnlse.md) for the physics and model.

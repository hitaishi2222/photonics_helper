# Raman cascade (CW) and RIN transfer

Continuous-wave multi-order Raman cascade, its conservation diagnostics, and the linearized
relative-intensity-noise transfer function. Provenance-checked benchmark fixtures for
Mermelstein 2003, Keita 2006 and Zhu 2007. Docstrings are the source of truth, rendered with
[mkdocstrings](https://mkdocstrings.github.io/) (numpydoc style).

See [Raman cascade: power flow and RIN transfer](../raman-cascade.md) for the physics, the unit
conventions and which published targets reproduce.

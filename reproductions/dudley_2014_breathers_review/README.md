# Reference only — Dudley, Dias, Erkintalo & Genty (2014)

**Reference:** J. M. Dudley, F. Dias, M. Erkintalo, G. Genty, "Instabilities,
breathers and rogue waves in optics," *Nature Photonics* **8**, 755–764 (2014).
**DOI:** [10.1038/nphoton.2014.220](https://doi.org/10.1038/nphoton.2014.220)
**Open copy:** [arXiv:1410.3071](https://arxiv.org/abs/1410.3071)

This folder holds the paper (`nphoton.2014.220.pdf`, `.txt`) and page images
(`paper_pages/`) as reference material. It is **not** a numerical reproduction.

The review is narrative: it classifies optical rogue waves by generating
mechanism (MI/breathers, Raman rogue solitons, dissipative systems, spatial
systems) rather than presenting one reproducible parameter set. Its
reproducible analytic content overlaps the two dedicated reproductions:

- the soliton-on-finite-background (breather) family, including the Akhmediev
  and Peregrine solutions → `../kuznetsov_ma_2012_breather/` and
  `../narhi_2016_mi_breathers/`;
- modulation instability gain and noise-driven breather emergence →
  `../narhi_2016_mi_breathers/`;
- supercontinuum / rogue-soliton dynamics →
  `../dudley_2006_scg/`.

A separate reproduction folder can be added later for the second-order
(Darboux) breather-collision profile if a specific figure is chosen.

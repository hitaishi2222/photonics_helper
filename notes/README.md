# notes

Working documents that are not part of the documentation site and not part of the
library's contract. They are kept because they record why things are the way they
are.

- `GAP.md`: the four gaps that blocked chalcogenide multimode SCG, and how each
  was closed.
- `PLAN.md`: the plan and progress tracker for the literature-reproduction work.
- `REVIEW.md`: the full project code review from 2026-10-13.

The bug register lives at the repository root as [`ISSUES.md`](../ISSUES.md)
because source comments cite it by number (`ISSUES.md #0`, `#11`, and so on).

Reader-facing documentation is in [`docs/`](../docs/index.md) and follows
[`docs/STYLE.md`](../docs/STYLE.md).
